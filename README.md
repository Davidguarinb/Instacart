# Instacart
Proyecto de práctica de Business inteligence para entender el comportamiento de los usuarios de la plataforma instacart.

Hábitos de compra Instacart.

Instacart es una plataforma de entregas de comestibles donde la clientela puede registrar un pedido y hacer que se lo entreguen, similar a Uber Eats y Door Dash. Este conjunto de datos particular fue lanzado públicamente por Instacart en 2017 para una competición Kaggle.

En este proyecto se realiza un ejercicio de procesamiento, manipulación, análisis y visualización de datos con las librerías Pandas y Matplotlib. La idea es identificar patrones de compra y el comportamiento de los usuarios para saber qué días y horas reciben más pedidos. Además, de los artículos que se incluyen con mayor frecuencia y el orden en que añaden al carrito de compras.

Para usar el código solo debes descargar el notebook (donde hay indicaciones de escritura del código) y los datasets. Luego se deben añadir las rutas al archivo al llamarlas en Python y posteriormente correr el código.
